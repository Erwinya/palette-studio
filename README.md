# Palette Studio

Build color palettes, tune hue, check WCAG-ish contrast, and export HEX values.

Flutter desktop/mobile demo.

## Status

Project scaffolding is in place. Palette UI, contrast helpers, and pubspec will land in follow-up commits.

## Planned setup

```powershell
flutter create . --project-name palette_studio
flutter pub get
flutter run
```
